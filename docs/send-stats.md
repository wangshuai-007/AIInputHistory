# AI 发送统计

AI Input History 1.32.0 起将原“AI 对话统计”改为“AI 发送统计”。统计目标是反映实际使用量，而不是会话数量。

## 统计口径

- 每次扩展确认发生了一次文本发送，就累计 `1` 次。
- 同一个会话连续发送多条消息，每条都会分别计数。
- 按 AI 类型分别统计，并提供全部 AI 汇总。
- 展示四个维度：总发送、今日、本周、本月。
- 周按浏览器本地时间计算，星期一作为一周开始。
## 与输入历史的关系

发送统计与输入历史使用独立数据结构保存。历史记录的保留上限不会裁剪发送统计，因此即使发送历史只保留最近若干条，总发送次数仍会继续累计。

“清空统计”只清空发送统计，不删除输入历史；“清空历史”也不会清除发送统计。

## 1.31.x 升级说明

1.31.x 保存的是按会话 URL 去重后的会话统计，无法从这些数据反推出真实历史发送次数。1.32.0 将统计 schema 升级到 v2；检测到旧 v1 数据时从 0 开始重新累计，避免把旧会话数错误显示成发送次数。

统计数据仅保存在浏览器本地 `chrome.storage.local`，不发送给开发者。
