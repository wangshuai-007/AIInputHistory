# ChatGPT Queue 排队

AI Input History 1.31.0 起支持 ChatGPT Queue。当前一轮仍在生成时，再发送的新文本不会打断当前回复，而是进入当前会话的本地 Queue；上一轮确认结束后再按 FIFO 顺序自动发送。

## 基本行为

- ChatGPT 空闲时，Enter、发送按钮和表单提交保持原生直接发送，不经过 Queue。
- ChatGPT 正在等待或生成回复时，新文本进入 Queue。
- Queue 每条消息都可“编辑”“撤回”或“立即发送”。
- 自动发送只会点击 ChatGPT 明确的发送按钮，语音、麦克风和其他 submit 按钮不会作为发送目标。
- 自动发送后，只有会话 DOM 中真正新增了与 Queue 内容匹配的 user turn，才认为发送成功并移出 Queue。
- 第一条 Queue 真正发出后，后续消息继续等待这一轮回复结束，不会连续一次性全部发送。

## 异常恢复

某条 Queue 自动发送后，如果 10 秒内仍无法确认 ChatGPT 真正接收，扩展会把它标记为“发送未确认”。该消息继续保留，可重新编辑、撤回或点击“立即发送”，但它不会继续占用发送锁，后面的正常 Queue 可以继续处理。

如果 RequestTiming 因网页状态异常长期未结束，但页面已经没有生成状态且最后回复明确完成，超过 2 分钟后 Queue 不再让该旧计时阻塞新的直接发送或自动出队。也可以右键悬浮计时按钮选择“停止计时”手动清除当前观察状态。
