# ChatGPT Pro 模型次数：使用与排查指南

> 适用于 AI Input History **1.37.16** 及以后版本。本功能默认关闭，只作用于 ChatGPT。页面内的次数是扩展根据本机数据和当前套餐设置计算或展示的值，**不是 OpenAI 官方实时剩余额度**。

## 快速启用

1. 登录 [ChatGPT](https://chatgpt.com/)，保持至少一个 ChatGPT 标签页打开。
2. 点击浏览器工具栏的 **AI Input History** 图标，进入「ChatGPT 专属设置」。
3. 将 **「记录 Pro 模型次数」** 从关闭切换为开启。它与「跟踪请求耗时」是两个独立开关，无须同时启用。
4. 扩展在**开关成功保存后**自动执行一次「读取当前账号套餐」：显示「正在读取当前 ChatGPT 登录信息…」，随后显示分类结果。**不需要再点击读取按钮**。
5. 如只读到了「Pro / Business（档位未确认）」、识别失败，或订阅金额 / Business 席位与实际不符，请在「ChatGPT 套餐档位」下拉框中**手动选择正确档位**。原来的「读取当前账号套餐」按钮可用于再次尝试。
6. 在 ChatGPT 输入框右侧的模型菜单中真正选中 **Pro**，此时原生模型按钮内部显示类似 **`Pro (15) ▾`** 的小号数字。新的 Pro 请求被确认后，本地次数和数字会刷新；选择普通模型则不显示。

升级已加载的解压扩展时，请在 `chrome://extensions` 或 `edge://extensions` 点击**重新加载**，然后刷新已有 ChatGPT 标签页。**不要卸载再安装**，否则可能丢失扩展本地的历史和计数。

## 自动读取套餐的范围

- **触发时机**：仅用户主动将 Pro 计数由「关 → 开」且设置保存成功后触发。打开弹窗、刷新 ChatGPT、同步其他设置、保持「开」或单独「关闭」不会触发读取。再次关闭并开启，会再查一次。
- **查找页面**：优先尝试当前窗口的活动 ChatGPT 标签页；失败时可尝试其他已打开且已登录的 ChatGPT 标签页。不要求额外的浏览历史读取权限。
- **读取内容**：通过 ChatGPT 同源的登录会话、账号列表与必要时的当前用户 Business 成员席位字段进行只读分类。**不是订阅账单接口**，不保证返回 Pro $100 / $200 / $500 的具体价格层级。
- **Business 席位**：明确的 Standard / Premium 席位可以识别；旧字段 `seat_type=default` 仅作 **Business Standard 兼容推断**，并在弹窗明确提示不属于官方精确确认。若账号下有多个工作区，或无法精确匹配当前成员，请手动检查工作区成员的 Seat type。
- **读取失败**：不会关闭 Pro 次数记录，不会清空本机统计，也不会覆盖已确认的套餐。读取进行时如果手动改选套餐，手动选择优先；自动读取与手动重读同时触发时不会重复请求。

## Pro 按钮中的数字怎么理解？

| 按钮内显示 | 含义 |
| --- | --- |
| `Pro (15) ▾` | 可显示的剩余数字；可能是本机按当前档位和已记录次数的估算，也可能来自 ChatGPT 页面明确展示的额度提示 |
| `Pro (≤15) ▾` | 仅能确认一个共享限额上界，**不能**当作该模型精确的剩余可用次数 |
| `Pro (?) ▾` | 当前档位或模型额度不足以确定数字，需要在弹窗检查套餐，或等待 ChatGPT 提供明确额度提示 |
| 非 Pro 模型 | 不显示 Pro 次数，避免将订阅身份误当作正在使用 Pro |

数字使用模型按钮内部的细小灰色括号样式，不增加弹窗提示或独立点击区域。点击数字所在位置仍会打开 ChatGPT 自带的模型选择菜单。为了界面简洁，数字**没有额外的悬停解释**；判断是否可信请以弹窗的套餐识别状态和上表为准。

**重要限制**：本机估算只扣除这个浏览器由扩展记录的请求，不包含手机 App、其他设备 / 浏览器的使用，也不能准确还原 OpenAI 可能采用的滚动日 / 周 / 月重置窗口。插件不会为了显示数字而调用未经确认的官方配额接口。示例次数及套餐限额是扩展的本机配置口径，**不可作为官方最新权益承诺**。

## 请求如何计次，在哪里查看？

- 只有明确识别到**当前选中 Pro 模型**并确认的新请求才计一次；普通模型、菜单里未选中的 Pro 项和仅有 Pro 订阅身份都不会计入。
- 页面发送确认、实际生成和可识别的网络请求按标签页、请求时间与模型信号**合并去重**；网络路径需要成功 HTTP 结果，失败请求不应被当作已完成的有效使用。刷新、切换会话及跨标签页同步不会故意重复扣次，但网页更新可能造成漏计或误判。
- 扩展弹窗的「Pro 模型使用次数」显示**累计、今日、本周、本月**以及逐日 / 逐周 / 逐月趋势。日期窗口按本机日历划分，不等于账号后台的实际限额周期。
- 「重置本地」仅针对**本月已用**的本机统计口径执行重置，保留累计、其他月份和每日 / 每周历史；操作**不会重置 ChatGPT 官方额度**，也不会重写过去无法确认的历史请求。

## 常见问题

**开启后显示未连接、`no-content-script`**

请确认有已登录的 ChatGPT 标签页，先在扩展管理页重新加载扩展，再刷新 ChatGPT 网页，重新点击「读取当前账号套餐」。如果当前页不是 ChatGPT，扩展会尝试其他已打开的 ChatGPT 标签页；都没有接收端时会返回提示。不要为此卸载扩展。

**账号显示 Business，但无法准确区分 Standard / Premium**

工作区类型不代表每位成员的席位类型。检查工作区设置里的成员 Seat type，并手动选择；旧式 `default` 映射只可视为兼容推断，不能保证等于新版本付费席位。

**已开启记录且选了 Pro，但按钮内没有数字**

先确认真实输入框的模型按钮显示 Pro，而不是页面顶部显示的「Pro 套餐」身份。刷新页面后，在 ChatGPT 普通开发者工具控制台可用下列**只读**代码检查扩展状态：

```js
({
  version: document.documentElement.getAttribute("data-aih-pro-version"),
  state: document.documentElement.getAttribute("data-aih-pro-state"),
  count: document.querySelector("[data-aih-pro-remaining]")?.textContent ?? null
})
```

`shown` 表示显示成功，`disabled` 表示开关未开启，`no-pro-control` 表示未定位到实际 Pro 模型控件。Manifest V3 内容脚本处于隔离环境，普通网页控制台里 `AIInputHistory is not defined` **不能证明扩展没有加载**。

**本机计数似乎不准确**

扩展只记录可确认的新请求，不会自动倒推版本升级前漏记的历史，以防错扣。可在「计时与通知诊断日志」筛选或导出脱敏记录排查，不需要提供聊天文本或登录凭证。

## 隐私和权限

Pro 次数默认关闭；开启后扩展只读 ChatGPT 会话请求的模型 / 模式和 HTTP 结果以辅助计数。**用户主动开启时的自动套餐读取**与手动按钮读取，都只向 ChatGPT 同源接口发起请求；必要的短期访问令牌仅在内存中用于相应同源请求，不写入本机日志、套餐设置、导出内容，也不向扩展开发者上传账号数据。网络缓存只保存有限的脱敏请求元数据；不保存原始请求正文、提问、回复、Cookie 或授权头。详情见 [双语隐私政策](../store-assets/privacy-policy.md)。
