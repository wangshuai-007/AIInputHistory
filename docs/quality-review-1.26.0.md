# 1.26.0 检查与优化记录

## 范围

检查历史存储、固定保护、多窗口一致性、输入与发送判断、面板和设置交互、发布脚本。延续既有绿色深浅主题与同排筛选，不新增权限或运行时依赖，不修改云端 IAM，不自动推送或送审。

## 修复

- 同页面多窗口草稿按会话隔离，发送只清除该会话草稿；兼容旧格式记录。
- 快照去重限定到当前会话；重复固定同一草稿不会创建多个永久副本。
- 设置按字段在写锁内合并，避免开关、语言、保存间隔互相覆盖；设置页跟随其他窗口的存储变更。
- 输入保存操作串行处理，避免旧快照在发送后重新写回草稿；计时器避免重叠保存，切换输入时保留正确上下文。
- 页面初始化与重新启用悬浮按钮时查找现有输入框；重复聚焦不重置自动保存间隔。
- 延迟换行不会在 40ms 就被标为发送；页面移除输入框和发送按钮右键不再虚构发送记录。
- 历史面板不再把原生按钮 Enter 当成插入历史；网站下拉 Escape 与清除确认对话框保持各自行为。
- 历史搜索只接受最新请求结果，刷新按记录 ID 保留选择；上下键仅更新选中样式，减少整列表重建和焦点丢失。
- 下拉选项不变时不重建菜单；短视口菜单不再强制占用超出可用空间的 96px。
- 设置页版本读取 manifest，修复长期显示 v1.23.0；面板错误提供可见提示。
- 图标请求限制同源、不携带 Cookie/Referrer、不跟随重定向，并设置超时；不可用时保留本地图标。
- CD 校验 Chrome 版本范围、tag/checkout/事件 SHA 一致性，避免覆盖后台处理中上传；JSON 异常不泄露原始远程内容，不重试不确定的写请求。
- 构建增加全部运行时 JavaScript 语法检查与 manifest/package 版本一致性验证。

## 验证

- Node 自动测试覆盖存储、并发、导航、输入队列、发送检测、固定、搜索竞态、设置同步、图标请求和 CD。
- 本地演示页面浏览器验证：固定/解除固定、图钉 Enter、固定筛选、清空提示及 Enter 取消、下拉 Escape、中文布局。
- 打包执行 manifest、语言包、入口文件、运行时脚本语法、商店素材检查。

## 尚存边界

- 未登录各家真实 AI 网站逐一回归，输入识别仍依赖页面 DOM 与交互行为；不能保证网站改版后所有路径都适配。
- “发送尝试”不是服务器送达确认；保留网页异常时提示词的需求与误识别之间仍有启发式判断边界。
- 全局存储锁仍使用 15 秒租约；极端超时或后台进程重启不属于已证明安全的并发条件。
- 固定历史不自动淘汰，仍受浏览器存储容量限制；写入失败不会通过删除固定消息来腾出空间。
- CD 未调用真实 Google 发布 API；OIDC 信任 tag 中的工作流路径，具有发布 tag 写权限的人应视为发布管理员。更严格隔离需要修改云端信任与可复用工作流，未擅自实施。
