# AI 输入历史

面向 Chrome、Edge 等 Chromium 浏览器的 Manifest V3 扩展。它会识别网页中的聊天输入框，将草稿、定时快照和实际发送前的内容保存在 `chrome.storage.local`，不上传任何输入数据。

## 功能

- 默认只在内置 AI 网站启用；可在扩展设置中添加自定义域名，启用该网站的 `textarea`、`contenteditable` 和聊天文本框追踪。
- 内置 Gemini、Grok、GLM、Qwen、ChatGPT、Claude、Google AI Studio、DeepSeek、Copilot、Perplexity、Kimi、豆包、腾讯元宝、文小言、Mistral、Poe、Meta AI 和 You.com 的站点识别与本地品牌图标资源，并增强常见富文本输入框和发送按钮识别。
- Copilot、Perplexity、Kimi、豆包包含独立的输入框与发送按钮选择器；支持 Copilot 开放 Shadow DOM、Kimi/豆包 Slate 富文本编辑器及 Perplexity 问答输入框。
- 输入时持续保存当前草稿，自动快照间隔按秒配置（默认 60 秒，范围 1–3600 秒）；内容未变化时不会重复写入。
- 根据页面的真实提交行为识别发送：表单提交、发送按钮点击、输入框实际清空，或网页拦截 Enter 且内容保持不变时才记录；Enter/Shift+Enter 产生换行或正文变化时不会误标记。
- 对内置 AI 网站，按下明确的发送快捷键时会先记录发送内容，再交给网页处理；即使 ChatGPT 页面请求失败、没有返回回答或输入框未清空，提示词也不会丢失。自定义域名仍使用页面实际清空/提交行为判定，避免把换行误记为发送。
- 全部历史默认保留最近 100 条，带 Enter 图标的发送记录默认最多保留 10 条。
- 输入框左侧显示悬浮历史按钮，长按按钮可自由拖动；历史面板可拖动标题调整位置，位置按网站保存在本地。
- 悬浮按钮支持右键隐藏；隐藏后仍可使用 `Ctrl+R`，也可在扩展设置中重新开启。
- 历史面板默认仅显示当前网站记录；带 AI Logo 的自定义下拉菜单将“全部网站”置于首项，并可切换其他网站。面板同时支持全文搜索、“仅发送记录”筛选和一键清除。
- 访问网站时优先读取并本地缓存页面当前 favicon，筛选菜单使用网站实际图标；打包图标仅作离线回退。
- 历史面板会识别网页的 `dark` / `data-theme` / `color-scheme` 和背景亮度，网站切换深浅主题时自动同步，无需刷新。
- 在输入框中按 `Ctrl+R` 打开历史；面板内用上下键选择、Enter 插入、Esc 关闭。
- 输入框光标位于开头或结尾时，可用上/下键按时间切换历史；多行编辑时不会无条件抢占方向键。
- 扩展弹窗可调整历史上限、发送记录上限和自动快照间隔，并可清空全部本地数据。

## 安装

1. 打开 `chrome://extensions` 或 `edge://extensions`。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展”，加载本项目目录。
4. 刷新已打开的 AI 网站，在聊天输入框获得焦点后即可使用。

## 快捷键说明

`Ctrl+R` 是浏览器原生刷新快捷键。扩展只在识别到的聊天输入框获得焦点时拦截它；未聚焦聊天框时仍执行页面刷新。个别网站或浏览器可能优先处理原生快捷键，此时可直接点击输入框旁的历史按钮。

## 隐私与权限

- `storage`：在浏览器本地保存输入历史、草稿和设置。
- `<all_urls>` 内容脚本：让不同实现方式的 AI 网站都能使用输入历史。扩展不读取网络响应，不发送遥测，也不请求远程服务。

由于扩展覆盖所有站点，提交到浏览器商店时需要在隐私说明中明确其本地存储用途。密码框、禁用输入框和无法编辑的元素不会被记录。
