# AI 输入历史设计系统

## 产品表面
AI 页面内的历史面板、悬浮入口和扩展设置页；历史查找与恢复优先。

## 美学方向
延续现有森林绿、紧凑工具界面，不引入新的品牌风格。

## 设计 token
CSS 变量 --bg/--surface/--line/--text/--muted/--accent/--accent-strong；深浅主题沿用现有值。Segoe UI 与 Microsoft YaHei UI；标题 15px，正文 13px，元数据 10–11px。危险色使用暖红。

## 布局策略
面板最大宽 400px，保持视口边距。网站下拉与三种类型筛选默认同排，网站区域最小宽 120px，较长名称省略；窄视口空间不足时自动换行。历史列表独立滚动。

## 组件与模式
每条记录的图钉按钮与文本恢复按钮独立，禁止嵌套按钮。已固定记录显示绿边、文字标识及图钉按下态。

## 状态覆盖
固定写入期间禁用按钮，失败显示可见错误，成功刷新列表并恢复焦点；清空确认明确保留固定消息。空列表沿用空状态。

## 记忆点
绿色图钉与记录左侧细线表示需要长期保留的内容。

## 动效策略
沿用保存与面板入场动效，固定状态不额外闪烁；尊重 prefers-reduced-motion。

## 无障碍要求
图钉具有本地化名称、aria-pressed 和可见焦点；支持 Enter/空格触发，不误恢复消息。

## 内容语气
中英文使用固定/解除固定、Pin/Unpin，清除提示准确说明保留范围。

## 禁止事项
不使用 emoji 图标；不添加营销区块或额外强调色；不隐藏危险操作的后果。

## 约束定义
仅一种绿色强调体系；三种类型筛选；固定记录保持原时间顺序。

## 实现备注
面板 CSS 位于 src/history-panel-style.js，交互位于 src/history-panel.js；使用本地截图夹具验证实际组件。
