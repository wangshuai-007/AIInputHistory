# Chrome Web Store 商店文案（简体中文）

## 名称

AI 输入历史

## 简短说明

在 AI 聊天网站本地保存输入草稿和发送记录，支持搜索、筛选及快捷恢复。

## 详细说明

AI 输入历史帮助你找回尚未发送、页面异常或误操作导致丢失的提示词。输入历史默认只保存在当前浏览器，不会上传到开发者服务器；只有你主动开启回复完成通知时，才会向你选择的通知服务发送配置的通知内容。

主要功能：

- 自动保存聊天输入草稿和定时快照；
- 实际发送后合并递增快照，只保留最终发送记录；
- 使用上下键像 Chrome DevTools Console 一样切换以前的输入；
- 按网站筛选、全文搜索，并可只查看发送记录；
- 支持 ChatGPT、Claude、Gemini、Grok、DeepSeek、Copilot、Perplexity、Kimi、豆包、Qwen、GLM 等主流 AI 网站；
- 可手动添加其他 AI 网站域名；
- 支持中英文界面、深色模式、自定义快捷键和可移动悬浮按钮；
- ChatGPT 可跟踪发送到回复完成的耗时，并可在完成后发送可选通知；
- 通知支持浏览器、Bark、Server酱、PushPlus、ntfy、Gotify、钉钉、飞书、企业微信机器人及自定义 HTTP 请求；
- 一键清除全部本地记录，删除前会明确确认。

隐私说明：扩展读取已支持或用户添加网站中的聊天输入、页面标题和域名来提供本地历史。历史默认不离开浏览器；只有用户主动开启外部完成通知时，通知摘要或用户显式配置的模板数据才会发送到所选服务。数据不会发送给开发者，不会出售，也不会用于广告或分析。
